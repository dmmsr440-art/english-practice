1. 消えるタケコプターの法則
語末の破裂音 T・K・P・D・G・B（覚え方：TKP＝タケコプター＋濁点のDgB）は弱く発音されるか消える。-ing の末尾 G も消える。
例: It → イッ(t) / look → ルッ(k) / morning → モーニン
2. 子から母への法則
前の単語が子音で終わり、次が母音（A・E・I・O・U + Y）で始まると音がつながる。
例: look at → ルッカッ / in a → イナ / Thank you → サンキュー
3. 双子の法則
同じ子音が連続すると前の子音は読まない（音ベースで判断、T と D は仲間扱い）。
例: want to → ウォントゥ / bad day → バッデイ / with the → ウィザ
4. Lの洗脳を解く法則
単語の後ろの方にある L は「ダークL」になり、ラ行ではなく「ウ」「オ」に近い音になる。
例: help → ヘゥ(p) / cool → クーゥ / apple → アポー
5. TDLの法則
T や D が母音（AEIOU＋Y・L・R）に挟まれると L に近い音（日本語のラ行）になる。※ T にアクセントがある時は変化しない。
例: water → ワラ / computer → コンピューラー / Let it go → レリゴー
6. TDを飲み込むNの法則
T や D が N と一緒になると消える。①N が次の T/D を飲み込む、②N が手前の T/D を飲み込む、の2パターン。
例: Internet → イナネッ / curtain → カーン / don't → ドウン
7. Hの隠れんぼの法則
have / has / had / he / his / him / her の H は文の途中に登場すると消える（文頭では発音）。
例: ask him → アスキム / should have → シュダヴ / tell her → テラー
